# Week 6: Association, Comparison, and the Target

Edit **index.qmd**. It is the source for the student slides, presenter slides, visible-notes deck, and instructor notes.

The deck begins with the unfinished Week 7 bridge from descriptive claims to descriptive tools. It then uses Junn and Masuoka, *Thinking Clearly with Data*, and Lundberg, Johnson, and Stewart to develop association, covariance, correlation, comparison sets, and estimands.

## Build

Run `python3 week-06/build.py` from the slides repository root.

Outputs:

- `docs/week-06/student.html` — student deck with notes and Speaker View removed
- `docs/week-06/presenter.html` — presentation with notes available in Speaker View
- `docs/week-06/with-notes.html` — slides with notes visible
- `docs/week-06/instructor-notes.html` — standalone instructor guide
