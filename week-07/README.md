# Week 7: Measurement and Description

Edit **index.qmd**. It is the source for the student slides, presenter slides, visible-notes deck, and instructor notes.

The deck uses media bias as the running case. It introduces conceptualization and operationalization, examines Kim, Lelkes, and McCrain's campaign-finance-weighted visibility measure and its validation, develops indicator, typological, network, trend, and correlational descriptive claims, and introduces distributions, means, medians, modes, variance, and standard deviation.

## Build

Run `python3 week-07/build.py` from the slides repository root.

Outputs:

- `docs/week-07/student.html` — student deck with notes and Speaker View removed
- `docs/week-07/presenter.html` — presentation with notes available in Speaker View
- `docs/week-07/with-notes.html` — slides with notes visible
- `docs/week-07/instructor-notes.html` — standalone instructor guide
